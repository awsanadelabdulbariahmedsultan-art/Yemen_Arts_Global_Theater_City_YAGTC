## 🏗️ أولاً: معايير اختيار شركة المقاولات العالمية (Tier-1 International Contractor)

لضمان تشييد "المدينة الوطنية اليمنية للفنون والمسرح العالمي" (YAGTC) بأعلى المواصفات الإنشائية المعمارية العالمية، يُشترط في الشركة المتقدمة للتنفيذ مطابقة المعايير الصارمة التالية:

1.  **الملاءة المالية والائتمانية:**
    *   تقديم قوائم مالية مدققة وموثقة لآخر **5 سنوات** متتالية، تثبت القدرة الكاملة على تمويل عمليات الشراء والتشييد وتأمين التوريدات للمسار السريع دون أي تعثر أو توقف مالي.
2.  **القدرة التقنية واللوجستية التخصصية:**
    *   امتلاك سوابق أعمال وخبرات مشهودة في مشاريع دولية مدمجة وشاملة تحاكي التصميم المعماري المعقد للمدينة، مع القدرة الكاملة على توطين التكنولوجيا داخل الجمهورية اليمنية وضمان سلاسل الإمداد.
3.  **الالتزام الصارم بالجدول الزمني المسرع:**
    *   تقديم خطة هندسية تفصيلية ومثبتة تضمن تسليم وتدشين المشروع كاملاً في غضون **9 إلى 12 شهراً** (المسار الفائق الفعالية) من تاريخ استلام الموقع والتمويل الأول، والقدرة على تشغيل نوبات عمل متواصلة على مدار الساعة (**Shifts 7/24**).
4.  **منظومة السلامة والضمان الفني الفائق:**
    *   الالتزام الصارم بتوفير نظام فحص وضمان ثلاثي الأبعاد وعزل مشدد تشرف عليه جهة مستقلة محايدة (**Third-Party Consultant**)، يضمن سلامة التربة، الهيكل الخرساني عالي المقاومة المبكرة، وجودة المواد الصلبة والمعدنية والمصنعة مسبقاً خارج الموقع لمدة تشغيلية لا تقل عن 50 عاماً.

## 👥 ثانياً: الهيكل التنظيمي لمجلس أمناء المدينة الفنية (Governance Structure)

تدار كافة مسارات وعمليات المدينة الفنية عبر هيكل مؤسسي رشيق مستقل يُحقق الشفافية المطلقة، ويفصل بين سلطات الرقابة، الاستشارات، والتنفيذ لمنع أي تضارب في المصالح وتسريع اتخاذ القرارات التنفيذية:

```text
                  +-------------------------------------------------------+

                  |              رئيس مجلس الأمناء / المبتكر             |
                  |          (المهندس/ أوسان عادل أحمد سلطان)            |
                  +---------------------------+---------------------------+

                                              |
                                              |
                     +------------------------+------------------------+

                     |                                                 |
                     ▼                                                 ▼
+------------------------------------------+     +------------------------------------------+

|      وحدة التدقيق المالي المستقلة        |     |       اللجنة الاستشارية الدولية          |
|      (شركة تدقيق مالية عالمية)           |     |     (ممثلو اليونسكو والصناديق السيادية)  |
+------------------------------------------+     +------------------------------------------+

                                              |
                                              |
                                              ▼
                  +-------------------------------------------------------+

                  |               المدير التنفيذي للمدينة                 |

                                              |

                      |                       |                       |

         |       والتطوير          | |    والربط الرقمي        | |       والهندسية         |
         +-------------------------+ +-------------------------+ +-------------------------+
```

### 📌 تفصيل الصلاحيات والأدوار الحوكمية:
1.  **رئيس مجلس الأمناء والمبتكر:** المرجعية السيادية والمالية العليا، وصاحب القرار النهائي في اعتماد التعديلات ومتابعة حوكمة الرؤية المعمارية (الأصالة المستقبلية).
2.  **وحدة التدقيق المالي المستقلة:** شركة حسابات دولية تراجع وتدقق كافة المعاملات المالية والمستخلصات الصادرة عبر **حساب الضمان المشترك (Escrow Account)** لضمان النزاهة التامة ومنع الهدر.
3.  **اللجنة الاستشارية الدولية:** تضم خبراء ممثلين لمنظمة **UNESCO** والصناديق التنموية (كالبنك الإسلامي للتنمية والصندوق السعودي) لتقديم الدعم الفني وضمان مطابقة المعايير التنموية ومقاييس الأداء (KPIs).
4.  **المدير التنفيذي (CEO):** يتولى الإشراف الميداني اليومي على القطاعات الثلاثة (الاستثمار والمطاعم والقرية، التشغيل والبث السحابي للمحافظات، والشؤون الهندسية وورش التصنيع) لضمان مسار الـ Fast-Track.
